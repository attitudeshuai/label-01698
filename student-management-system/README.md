# 学生信息管理系统

一个功能完整的学生信息管理系统，采用现代化的UI设计，支持多种功能模块。

## 功能模块

### 1. 用户认证模块
- ✅ 用户登录
- ✅ 用户注册
- ✅ 密码找回
- ✅ 权限管理

### 2. 学生基本信息管理模块
- ✅ 模板导入（支持Excel文件）
- ✅ 信息录入
- ✅ 信息修改
- ✅ 信息查询

**信息采集维度：**
- 姓名、性别、出生日期、民族、籍贯
- 身份证号、联系电话、家庭住址
- 父母姓名、父母职业、父母电话
- 是否重组家庭、是否留守儿童、疾病史

### 3. 学生行为管理模块
- ✅ 健康记录
- ✅ 奖惩记录
- ✅ 成长档案

### 4. 学生成绩管理模块
- ✅ 成绩导入
- ✅ 成绩分析（平均分、及格率、优秀率等）
- ✅ 趋势追踪（单科和总成绩走势图）
- ✅ 统计报表（班级报表、学科报表、学生报表、班级对比）

## 技术特点

- 纯前端实现，无需后端服务
- 响应式设计，支持各种屏幕尺寸
- 使用 Chart.js 实现数据可视化
- 现代化 UI 设计，美观易用
- 完整的交互逻辑

## 使用方法

1. 直接在浏览器中打开 `index.html` 文件
2. 使用以下默认账号登录：
   - **管理员账号**: admin / 123456
   - **教师账号**: teacher1 / 123456
   - **学生账号**: student1 / 123456
